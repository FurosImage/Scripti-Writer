# The Scripti Writer name and logo

The code of Scripti Writer is free software under the GNU General Public License, version 3
(see [LICENSE](LICENSE)). The license covers the code. It does not give permission to use the
name **Scripti Writer** or **Scripti**, or the Scripti Writer logo, for other products.

You're welcome to:

- share unchanged copies of Scripti Writer under its name,
- say that your project is "based on Scripti Writer" or "a fork of Scripti Writer".

If you publish a changed version, please give it a different name and icon, so writers can tell
it apart from the original.
